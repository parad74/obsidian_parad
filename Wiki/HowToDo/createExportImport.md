Для запуска всех трёх проектов можно написать:

> Машина, создай новый solution с Model, SelectParam и Code First ExportImport по нашим сохранённым правилам. Веди меня пошагово; начни с выбора имени сервиса, СУБД и остальных необходимых параметров.

Такой запрос охватывает весь стартовый комплект. Фраза «создай библиотеку Model» по текущим правилам запускает только два проекта. Создание migration и самой БД остаётся отдельными действиями.

Процесс я восстановила так:

- **Полный новый solution:** по одному выбрать недостающие параметры — сервис и расположение, СУБД, совместимый провайдер/EF/framework и версии, логическое имя БД, при необходимости файл и расположение. Производные имена показать, независимо не переименовывать. Проверить совместимость.
- **Стартовый результат:** `<Service>.sln`, локальная копия `Service.Model.EF.SelectParam`, Model с готовым комплектом и `NoEntityAttribute`, ExportImport с полной цепочкой `CommandResult`. Для переноса готового состава Excel не нужен.
- **Только Model:** два проекта — Model и SelectParam; без вопросов о БД и без создания ExportImport.
- **Интеграция:** использовать существующий solution и имеющиеся проекты, без дублирования и автоматической смены версий.
- **Новые объекты:** описание → Excel → проверенная и возвращённая книга → весь согласованный комплект одним проходом. По умолчанию — оба проекта и полная цепочка; явное ограничение сохраняется.
- **Дополнение существующих:** изменить только запрошенные части после согласования Excel. Отсутствующие зависимости уточнить; существующие поля автоматически не переделывать.
- **Attributes/NoEntity:** столбец добавляется в новую книгу; атрибуты относятся к свойствам DomainObject. `[NoEntity]` исключает свойство из Entity, конфигурации и всех четырёх методов маппера; конфликты с существующим хранением требуют решения.
- **Передача:** сборка, фактический результат, код для вычитки. Возврат Excel не означает вычитку кода. Затем проверка design-time готовности и точные команды migrations; выполнение каждого действия отдельно разрешает Parad.

**Проверяемая фраза однозначно задаёт полный стартовый состав**, несмотря на ещё не выбранные параметры. Она не разрешает автоматически выполнять migrations или создавать БД.

> Машина, создай новый solution с Model, SelectParam и Code First ExportImport по сохранённым правилам, с полным стартовым CommandResult. Веди пошагово: сначала спроси недостающие параметры.
