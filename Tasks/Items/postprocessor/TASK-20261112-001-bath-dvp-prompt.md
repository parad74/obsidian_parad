## Цель
Повторять процесс outvanna по новой картинке и названию каталога, с полным комплектом и записью в каталоге работ.

## Описание
Основание — запрос Parad и ответы 12.11.2026: условия обработки outvanna применять по умолчанию; до «выполняй» показать их информационно. Две соседние папки in<название>/out<название>; при занятости имени общий свободный цифровой суффикс без перезаписи. Кривые без указанных радиусов восстанавливать по рисунку, размеры соблюдать по подписям, аппроксимацию отмечать.

## Критерии приёмки
- Промт запрашивает отсутствующие картинку с размерами и название каталога.
- Перед выполнением показывает геометрию, условия и пути, ждёт «выполняй».
- После выполнения предусмотрены DXF, CUT/AIR_XY, PDF, проверки, папки и пополнение каталога.
- Старые размеры, пиксели и номера PARAD не становятся параметрами нового изделия.
- Запрос со словами «ванна» и «ДВП» направляется на промт; обсуждение промта не запускает изготовление комплекта.

## Ограничения
Не запускать новое изделие при создании промта. Не менять старые результаты. Новые вопросы — только при существенном пробеле или конфликте входных данных.
