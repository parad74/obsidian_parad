# TASK-20260812-008 — Создать архив отменённых задач

## Проект: General

- [r] Создать архив отменённых задач 🆔 TASK-20260812-008

## Цель

Убрать отменённые задачи из рабочих списков, сохранив их историю и доступность в отдельном представлении.

## Описание

Создать корневой список `Tasks/Cancelled.md`, подпапки `cancelled/` в проектных контекстах и правила перемещения отменённых и повторно открытых карточек.

## Критерии приёмки

| ID | Критерий |
| --- | --- |
| AC-1 | Отменённые карточки перемещаются в `cancelled/` своего проектного контекста |
| AC-2 | `Cancelled.md` показывает отменённые задачи с динамической группировкой по проектам |
| AC-3 | Отменённые задачи не отображаются в рабочих списках и в блоке задач Today на сегодня |
| AC-4 | При повторном открытии карточка возвращается из `cancelled/` в активную папку со статусом `Todo` |
| AC-5 | Правила закреплены в `AGENTS.md` |

## Ограничения

- Не считать отмену успешным завершением.
- Не добавлять дату `✅` отменённым задачам.
- Не использовать JavaScript-запросы Obsidian Tasks.
