# TASK-20260822-001 — Сохранить промпт замены текстуры камня

## Проект: General

- [r] Сохранить согласованный промпт замены текстуры материала на фотографиях интерьера 🆔 TASK-20260822-001

## Цель

Создать повторно используемый промпт для реалистичной замены материала на одной или нескольких фотографиях интерьера.

## Описание

Промпт принимает референс нового материала, обрабатывает все предоставленные ракурсы и определяет изменяемые поверхности по объекту, цвету, группе одинаковой отделки либо по правилу по умолчанию.

## Критерии приёмки

| Критерий | Ожидаемый результат |
| --- | --- |
| Параметры | Один референс материала и одна или несколько фотографий интерьера |
| Выбор поверхностей | Объект, цвет, точный список и формулировка «объект и всё такого же цвета» |
| По умолчанию | Основная столешница и поверхности того же материала |
| Несколько ракурсов | Отдельный согласованный результат для каждой фотографии |
| Сохранность | Остальной интерьер, ракурс, кадрирование и освещение не изменяются |
| Запуск | Обработка начинается только после отдельной команды «Выполни» |
| Масштаб | Указанный реальный размер плиты или образца используется как приблизительный ориентир |
| Рабочие файлы | Рядом с промптом описана временная структура artifacts/YYYYMMDD/in и out |
