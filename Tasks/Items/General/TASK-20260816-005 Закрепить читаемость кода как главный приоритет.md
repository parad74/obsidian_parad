# TASK-20260816-005 — Закрепить читаемость кода как главный приоритет

## Проект: General

- [v] Закрепить читаемость кода как главный приоритет 🆔 TASK-20260816-005

## Цель

Сделать понятность кода человеку главным правилом для всех проектов, в которых Машина создаёт или изменяет код.

## Описание

Добавить в `AGENTS.md` правила написания кода, ориентированные на ясный стиль образцов Microsoft для .NET Framework: не объединять несколько разных операций в одно сложное выражение, явно показывать порядок действий и предпочитать простые именованные конструкции, которые легче понять, отладить и рефакторить.

## Критерии приёмки

| ID | Критерий |
| --- | --- |
| AC-1 | Читаемость человеком явно установлена главным приоритетом при выборе между равнозначными реализациями |
| AC-2 | Несколько разных этапов обработки не скрываются в одном сложном выражении |
| AC-3 | Промежуточные значения и самостоятельные действия получают понятные имена |
| AC-4 | Правило объяснено порядком, удобством понимания, отладки и рефакторинга, а не только частотой чтения кода |
| AC-5 | Правило применяется ко всему создаваемому и изменяемому Машиной пользовательскому коду, не навязываясь сгенерированным или сторонним файлам |
| AC-6 | В конце правил традиции написания кода Microsoft зафиксированы как общий ориентир, а примеры .NET Framework — как понятный эталон читаемости |

## Ограничения

- Не запрещать языковые возможности C# только из-за их современности.
- Не выполнять механическое дробление, которое ухудшает связность и понимание кода.
- Не менять существующие архитектурные карточки без отдельной необходимости.
