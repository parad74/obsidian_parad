# TASK-20260812-004 — Создать страницу Today для задач

## Проект: General

- [x] Создать страницу Today для задач 🆔 TASK-20260812-004 ✅ 2026-08-12

## Цель

Создать ежедневное представление задач, в котором видны текущая работа, задачи с датой на сегодня независимо от статуса и задачи, завершённые сегодня.

## Описание

Добавить `Tasks/Today.md` с простыми запросами Obsidian Tasks и обеспечить запись даты завершения при переводе задач Codex в `Done`.

## Критерии приёмки

| ID | Критерий |
| --- | --- |
| AC-1 | Страница показывает задачи со статусом типа `IN_PROGRESS` |
| AC-2 | Страница показывает задачи, которые начинаются, запланированы или имеют срок сегодня, независимо от статуса |
| AC-3 | Страница показывает задачи с датой завершения сегодня |
| AC-4 | Между корневыми списками задач есть навигационные ссылки |
| AC-5 | В `AGENTS.md` закреплено добавление `✅ YYYY-MM-DD` при переводе задачи в `Done` |
| AC-6 | Ранее завершённые сегодня задачи имеют дату завершения и попадают в соответствующий блок |
| AC-7 | Карточки `Done [x]` перемещаются в подпапку `done/` своего проекта |
| AC-8 | При повторном открытии карточка возвращается из `done/` в корень папки своего проекта |

- Не перемещать в `done/` задачи `Checked`, `Cancelled` или любого другого статуса, кроме `Done`.
