# TASK-20260812-007 — Разделить ToDo и InProcess

## Проект: General

- [x] Разделить ToDo и InProcess 🆔 TASK-20260812-007 ✅ 2026-08-12

## Цель

Отделить задачи, работа над которыми ещё не начата, от задач, находящихся в процессе выполнения и проверки.

## Описание

Создать корневой список `Tasks/ToDo.md` для статусов `Todo` и `Important`, а в `Tasks/InProcess.md` оставить статусы `Doing`, `InProgress`, `Review` и `Checked`.

## Критерии приёмки

| ID | Критерий |
| --- | --- |
| AC-1 | `ToDo.md` показывает только задачи типа `TODO` |
| AC-2 | `InProcess.md` показывает только задачи типа `IN_PROGRESS` |
| AC-3 | Оба списка динамически группируют найденные задачи по проекту и статусу |
| AC-4 | Между `ToDo`, `InProcess`, `Today` и `OnHold` есть навигация |
| AC-5 | В `AGENTS.md` закреплено назначение обоих списков |

## Ограничения

- Не изменять канонический набор статусов.
- Не использовать JavaScript-запросы Obsidian Tasks.
- Не создавать статические заголовки отсутствующих проектов.
