## Цель

Сохранить по одному общему документу для каждого представления задач и разделять задачи внутри документа по проектному контексту.

## Описание

Организовать `InProcess`, `Today` и `OnHold` как корневые документы с отдельными разделами для `General` и каждого `Project ID`, не используя JavaScript в запросах Obsidian Tasks.

| ID | Критерий |
| --- | --- |
| AC-1 | Для каждого вида списка существует один корневой документ |

| AC-3 | Служебные папки `done/` и `on_hold/` не отображаются как отдельные проекты |
| AC-4 | Заголовок проекта отображается в конкретном списке только при наличии подходящих задач этого проекта |
| AC-5 | Запросы работают без включения JavaScript в Obsidian Tasks |
