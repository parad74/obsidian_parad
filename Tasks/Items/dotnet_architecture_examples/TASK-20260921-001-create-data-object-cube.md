## Цель

Создать переиспользуемую архитектурную карточку и рабочую инструкцию на основе текущих Model/SelectParam/ExportImport. Источник — файл описания данных в любом доступном для чтения формате. Последовательность по умолчанию: DomainObject → Entity → MappingEF → Repository.

## Описание

11 исходных последовательностей сохранены как примеры, а не закрытый список. Состав работы определяется запросом Parad и фактическим состоянием проекта: названные этапы создаются или дополняются, существующие части используются без дублирования. По умолчанию после проверки и возврата Excel выполняется DomainObject с парной коллекцией → Entity с конфигурацией и подключением к DbContext → MappingEF → Repository с интерфейсом. Запрос только Entity не запускает остальные этапы. При недостающих зависимостях уточни существующие пути либо расширение состава работы до генерации. Правила: [[Documents/Architectures/Cubes/DotNet/DomainObject - Entity - MappingEF - Repository#Гибкий состав работы и согласование модели]].

Карточка кубика определяет состав этапов, зависимости, вопросы, нормализацию входа, порядок согласования, проверку и продолжение с сохранённого состояния. После возврата утверждённого Excel весь запрошенный комплект создаётся одним проходом в обоих проектах либо только в прямо указанном проекте/составе. Дополнительных подтверждений каждого объекта или этапа нет; итоговый код показывается для вычитки.

## Критерии приёмки

- Сохранены все 11 последовательностей как примеры; состав работы определяется запросом, полная цепочка по умолчанию выполняется после утверждения Excel.
- Для каждого этапа определены необходимые входы, пути и создаваемые файлы.
- Модель проверена и возвращена Parad в Excel до записи кода; весь запрошенный комплект создаётся за один проход, затем показывается для вычитки.
- DomainObject включает парную коллекцию, Repository — интерфейс и реализацию.
- Согласованы зависимости одиночных этапов, состав Entity и гранулярность подтверждения.
- Рабочая команда и каталог ссылаются на карточку; старые инструкции не переопределяют её последовательность.
- Проверены согласованность документов и сохранность существующих материалов; практическое применение не заявляется выполненным без реальной проверки.
