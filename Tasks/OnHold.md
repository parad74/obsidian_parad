Здесь находятся задачи, принудительно исключённые из текущего процесса. Их нужно периодически пересматривать и принимать одно решение: оставить на паузе, вернуть в работу, завершить либо отменить.

```tasks
path includes Tasks/Items
status.type is ON_HOLD
group by heading
group by status.name
sort by due
sort by path
```
