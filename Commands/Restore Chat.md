# Restore Chat

## Назначение

Восстановить работу по заметке из `Chats/Codex/`: либо открыть исходную задачу Codex, либо загрузить сохранённый контекст в текущую новую задачу.

## Как вызвать

По точному пути:

```text
Прочитай и выполни Commands/Restore Chat.md.
Файл: Chats/Codex/YYYY-MM-DD <имя_чата>.md.
```

Если путь неизвестен:

```text
Прочитай и выполни Commands/Restore Chat.md.
Найди чат по имени: <часть_названия>.
```

## Инструкция для Codex

1. Найди заметку только внутри `Chats/Codex/`.
2. Если указан точный путь — используй его.
3. Если указана часть имени — найди подходящие Markdown-файлы без учёта регистра:
   - при одном совпадении используй его;
   - при нескольких совпадениях покажи список и попроси выбрать;
   - при отсутствии совпадений сообщи об этом и ничего не создавай.
4. Полностью прочитай корневой `AGENTS.md` и выбранную заметку чата.
5. Извлеки:
   - `codex_thread_id`;
   - рабочую папку;
   - цель;
   - выполненные действия;
   - принятые решения;
   - важные файлы;
   - нерешённые вопросы;
   - следующий шаг.
6. Проверь, что упомянутые важные файлы существуют. Не изменяй их во время восстановления.
7. Если пользователь просит вернуться именно в исходную задачу Codex и `thread ID` присутствует, открой:

   ```text
   codex://threads/<thread ID>
   ```

   Если открыть задачу инструментом невозможно, покажи пользователю готовую ссылку.
8. Если восстановление выполняется в текущей новой задаче, кратко сообщи:
   - какой файл загружен;
   - какова цель;
   - что уже сделано;
   - какие решения действуют;
   - какой следующий шаг;
   - какие вопросы требуют ответа пользователя.
9. После восстановления остановись. Не продолжай реализацию и не изменяй файлы, пока пользователь явно не попросит продолжить.

## Ограничения

- Не выбирай заметку наугад при нескольких совпадениях.
- Не считай заметку полной копией переписки: точная история находится в исходной задаче Codex.
- Не выполняй устаревший следующий шаг, если текущее состояние файлов ему противоречит; сначала сообщи о расхождении.
- Не изменяй `thread ID` в заметке.
