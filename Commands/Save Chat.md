# Save Chat

## Назначение

Сохранить текущее состояние задачи Codex в `Chats/`, чтобы позже можно было открыть исходную задачу или восстановить её контекст в новой задаче.

## Как вызвать

```text
Прочитай и выполни Commands/Save Chat.md.
Имя чата: <короткое_имя>.
```

Если имя не указано, используй текущее понятное название задачи Codex. Не используй автоматически сгенерированное общее название вроде `Обработать приветствие`.

## Инструкция для Codex

1. Определи текущую дату в часовом поясе `Asia/Tomsk` в формате `YYYY-MM-DD`.
2. Получи данные текущей задачи Codex:
   - `thread ID`;
   - `host ID`, если доступен;
   - название задачи;
   - рабочую папку.
3. Если `thread ID` недоступен через инструменты, попроси пользователя выполнить `/status` и передать ID. Не придумывай идентификатор.
4. Сформируй путь:

   ```text
   Chats/YYYY-MM-DD <имя_чата>.md
   ```

5. Если файл отсутствует — создай его. Если существует — обнови его без создания дубля и без потери прежних важных решений.
6. Запиши минимальный frontmatter:

   ```yaml
   ---
   type: codex-chat
   created: YYYY-MM-DD
   updated: YYYY-MM-DD
   codex_thread_id: <thread ID>
   codex_host_id: <host ID>
   codex_task_title: <название задачи>
   workspace: <рабочая папка>
   ---
   ```

7. Добавь прямую ссылку на исходную задачу:

   ```markdown
   [Открыть исходную задачу Codex](codex://threads/<thread ID>)
   ```

8. Сохрани разделы:
   - `Как продолжить работу`;
   - `Контекст и цель`;
   - `Что уже сделано`;
   - `Принятые решения`;
   - `Важные файлы`;
   - `Нерешённые вопросы`;
   - `Следующий шаг`.
9. Сохраняй факты и решения, а не внутренние рассуждения модели и не длинный журнал инструментов. Полная переписка остаётся в Codex.
10. В раздел `Как продолжить работу` добавь готовый текст:

    ```text
    Прочитай AGENTS.md и эту заметку полностью. Восстанови контекст,
    кратко назови цель, принятые решения, выполненные действия и следующий шаг.
    Не изменяй файлы, пока я не попрошу продолжить работу.
    ```

11. Проверь, что файл существует, читается, содержит правильный `thread ID` и следующий шаг.
12. Сообщи пользователю полный путь и ссылку на созданную или обновлённую заметку.

## Ограничения

- Не сохраняй секреты, токены, пароли и содержимое `.env`.
- Не выдумывай решения и выполненные действия.
- Не создавай полный экспорт каждой технической операции, если пользователь отдельно этого не попросил.
- Не перезаписывай поле `created` при обновлении существующей заметки.
