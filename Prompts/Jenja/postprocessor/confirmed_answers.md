Для этапа, выполненного для PARAD-002 25.09.2026, использовать три равнозначных названия:

1. **Расчёт траекторий и подготовка проверочного комплекта УП** — полное название.

Под этими названиями понимать один этап: расчёт рабочих траекторий XYZ, четыре проверочных NC для XY без резания и вращения шпинделя, таблицы координат и времени, черновики постпроцессоров и документация. ### 5.1. Порядок действий при продолжении работы

1. Сначала прочитать эту базу знаний и README нужного изделия. Восстановить последние решения, отменённые варианты, уже выполненные действия и точку продолжения. Не начинать работу и опрос заново.
