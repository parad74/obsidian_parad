# PARAD-018 — Круговой торец ванны по размерам

12.11.2026. Геометрическое исследование, без раскроя, CUT или изменения outvanna.

## Итог по последним указаниям Parad

Ориентироваться на цифры. Зелёная вертикаль вспомогательная, в геометрии не учитывать. Просмотрены [33.jpg](../invanna2/33.jpg) и [схема без зелёной заливки](../invanna2/photo_2026-11-12_19-19-33.jpg); указаны внутренние 1583 × 613 и наружные 1730 × 810 мм.

Для варианта полукруглого торца, согласующегося с видом схемы, достаточно **одной окружности радиуса 306,5 мм**: R = 613 / 2. Верхняя и нижняя четверти имеют один и тот же центр и радиус. Размеры сами по себе не доказывают, что реальный торец строго круговой; это размерное построение выбранной модели, а не точный CAD производителя.

Координаты: A — крайняя левая точка внутреннего выреза на середине высоты; X вправо, Y вверх. A = (0;0), O = (306,5;0) мм. Верхняя/нижняя точки полукруга: (306,5; ±306,5) мм. Уравнение: (x − 306,5)² + y² = 93942,25 мм². Если отсчитывать Y вниз от верхней линии внутреннего выреза, центр (306,5;306,5) мм относительно левого габарита выреза.

Если оба торца внутреннего выреза полукруглые, длина прямых между ними 1583 − 613 = 970 мм. Наружные габариты не определяют этот радиус; положение центра относительно наружной рамки не задано без отдельного условия центровки.

## Исправленное наложение — 13.11.2026

Актуальный результат: [полная окружность поверх исходника](circle_on_original_exact2.png), [SVG](circle_on_original_exact2.svg), [проверки и параметры](circle_on_original_exact2.json), скрипт `draw_exact_overlay.py`. Прежний ImageGen-вариант `circle_on_original.png` отклонён Parad: получился овал. Его не использовать для геометрии; сохранён как история неудачной попытки.

На чистом исходнике заново подобраны 368 точек левой чёрной дуги. Центр (365,159; 405,898) пикселя от верхнего левого угла, радиус 199,517 пикселя; RMS 0,200 пикселя. Верхняя и нижняя части дают центры с расхождением около 0,99 пикселя: оснований вводить два разных центра по этой схеме нет.

Для модели одного кругового торца, касающегося двух параллельных прямых на расстоянии 613 мм, R = 306,5 мм. Центр относительно крайней левой точки выреза на средней линии: X = 306,5 мм вправо, Y = 0. Надпись на изображении `R ≈ 306,5 мм`: это размер круговой модели, а не подтверждённый радиус производителя. Разные размерные масштабы схемы не позволяют объявить пиксельную подгонку точным физическим измерением.

Наложение построено математически, диаметры по X/Y равны; пиксели исходника вне прозрачного слоя аннотаций неизменны. Заливка не добавлялась. Исходный JPG сохранён. Отдельный новый PDF исследования не создавался: запрос ограничен картинкой. Для включения в общий процесс использовать актуальное наложение вторым шагом после исходника по промту Circle Radius on Image.

До уточнения «ориентируйся на цифры» выполнена подгонка по чёрной кромке: общий R199,52 px, центр (365,16;405,90) px; верх/низ дают центры на расстоянии 0,94 px. Одна окружность описывает 368 точек с RMS0,201 px. Неровная зелёная заливка не использована как контур.

Эти пиксельные результаты в `fit_results.json`, `boundary_points_pixel.csv`, `circle_fit_comparison.png` и `analyze.py` сохранены как предварительное исследование. Разные масштабы по четырём подписанным размерам несовместимы; полученные при растяжениях растра метрические подгонки и смещение зелёной линии не являются итоговыми размерами. `finalize_dimensions.py` фиксирует одноразовый переход отчёта к размерному построению; повторно его не запускать.
