# Temporary working artifacts

Этот каталог предназначен для временных входных и выходных файлов при работе с промптом [[../stone-texture-replacement]].

## Структура

Для каждого нового набора используй дату начала работы в формате YYYYMMDD:

```text
artifacts/
  YYYYMMDD/
    in/
    out/
```

- `in/` — референс материала и исходные фотографии интерьера;
- `out/` — результаты, которые Parad сохраняет после обработки.

Текущий рабочий набор:

- `20260822/in/`;
- `20260822/out/`.

## Как передать файлы Машине

Положи все входные изображения в папку `in` и в чате укажи путь, например:

```text
Входные файлы:
Prompts/Jenja/stone_08_2026/artifacts/20260822/in

Прочитай stone-texture-replacement.md.
Не начинай обработку до отдельной команды «Выполни».
```

После загрузки и проверки всех файлов напиши:

```text
Все файлы загружены. Выполни.
```

Полученные изображения сохрани вручную в соответствующую папку `out`.

## Временный характер

Содержимое датированных папок является временным рабочим материалом, а не постоянным источником истины.

- Рабочие изображения исключены из Git и не переносятся на другие компьютеры через репозиторий.
- Структура папок и эта инструкция сохраняются в vault.
- Файлы не удаляются автоматически.
- Нужный постоянный результат следует отдельно перенести в согласованное место хранения.
