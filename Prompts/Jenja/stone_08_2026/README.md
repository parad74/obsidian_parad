# Stone texture replacement prompt

Эта папка содержит промпт для реалистичной замены материала на фотографиях интерьера:

- [[stone-texture-replacement]] — основной промпт;
- README.md — инструкция по запуску.

## Лучший процесс использования

Работа разделена на два этапа:

1. загрузка промпта, референса, фотографий и уточнений;
2. запуск обработки отдельной командой **«Выполни»**.

Это важно, потому что фотографии могут загружаться несколькими сообщениями. Сам факт загрузки очередного файла не запускает обработку.

## Рабочие файлы рядом с промптом

Для временной работы используется понятная папка рядом с промптом:

```text
Prompts/Jenja/stone_08_2026/artifacts/YYYYMMDD/in
Prompts/Jenja/stone_08_2026/artifacts/YYYYMMDD/out
```

- В `in` Parad вручную помещает референс и исходные фотографии.
- В `out` Parad вручную сохраняет полученные результаты.
- YYYYMMDD — дата начала конкретного набора.
- Подробные правила находятся в [[artifacts/README]].

Отдельная папка `temp` не используется: `artifacts` уже является общей и понятной временной рабочей областью.

Рабочие изображения исключены из Git. Они остаются локальными и не переносятся через репозиторий на другие компьютеры или аккаунты.


## Использование в Codex

В начале новой задачи напиши:

```text
Прочитай полностью:
Prompts/Jenja/stone_08_2026/stone-texture-replacement.md

Пока не запускай обработку изображений.
Я загружу референс и фотографии несколькими сообщениями.
Жди отдельной команды «Выполни».

Целевые поверхности: <описание>.
```

Строку «Целевые поверхности» можно:

- заполнить точным списком: «столешница, фартук и остров»;
- указать через объект: «подоконник»;
- указать через объект и цвет: «стол и всё такого же цвета»;
- удалить — тогда сработает правило по умолчанию из промпта.

Затем последовательно загрузи:

1. референс нового материала;
2. все фотографии интерьера;
3. дополнительные уточнения, если они нужны.

Файлы удобно подписывать:

```text
Референс нового материала.
```

```text
Фото интерьера 1 из 3.
```

```text
Фото интерьера 2 из 3.
```

После загрузки последнего файла отправь отдельное сообщение:

```text
Все файлы загружены. Выполни.
```

До этой команды обработка изображений не должна начинаться.

## Использование в обычном ChatGPT

Обычный ChatGPT не получает автоматический доступ к локальному vault. Используй один из способов:

1. прикрепи файл stone-texture-replacement.md к новому чату;
2. добавь этот файл в материалы проекта ChatGPT и веди связанные чаты внутри проекта;
3. скопируй текст промпта вручную, если прикрепить файл невозможно.

После прикрепления файла напиши:

```text
Полностью прочитай приложенный файл stone-texture-replacement.md.
Не запускай обработку до отдельной команды «Выполни».
Я загружу референс и фотографии несколькими сообщениями.
```

Далее загрузи материалы и заверши отдельной командой:

```text
Все файлы загружены. Выполни.
```

## Что происходит до команды «Выполни»

До запуска Машина может:

- подтверждать получение файлов;
- определять, какой файл является референсом, а какой — фотографией интерьера;
- перечислять полученные материалы;
- задавать один конкретный уточняющий вопрос при неоднозначности.

До команды «Выполни» Машина не должна запускать генерацию или редактирование изображений.

## Новый набор фотографий

Если после выполнения добавлены новые фотографии, они считаются новым набором. Для них снова требуется отдельная команда:

```text
Выполни.
```
