## Контекст

Пользователь — архитектор и разработчик .NET-приложений на C#. Возможные типы приложений: веб, desktop, WPF и другие проекты на .NET.

Цель — постепенно создать понятную связку:

```text
Obsidian: ТЗ, спецификации и задачи
    ↓
Codex: анализ, планирование и реализация
    ↓
Sources: исходный код C#/.NET
    ↓
GitHub: репозитории, история, pull request и CI
    ↓
Obsidian: результат и подтверждение выполнения задач
```

На текущем этапе система намеренно остаётся минимальной. Новые шаблоны, свойства, статусы, навыки и автоматизация добавляются только после возникновения понятной практической необходимости.

## Принятые решения

1. Obsidian должен стать источником истины для задач; GitHub Issues пока не дублируются.
2. Vault и приложения предполагается хранить в отдельных приватных репозиториях GitHub.
3. `Sources/` предполагается исключить из Obsidian Sync и будущего Git-репозитория vault.
4. Для каждого приложения в будущем планируется единая команда проверки `eng/verify.ps1`, которую запускают Codex и GitHub Actions.
5. Пока используются стандартные возможности Obsidian Tasks и Obsidian Projects.
6. Собственные шаблоны Task и Project будут введены только тогда, когда станет понятна их реальная необходимость.
