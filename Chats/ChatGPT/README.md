# Архивы чатов ChatGPT

В этой папке хранятся локальные снимки своих и доступных Parad чатов ChatGPT.

Инструкция по сохранению: [[ChatGPT/How ToDo#Как заархивировать любой чат из ChatGPT]].

Основной формат имени:

```text
YYYY-MM-DD <Название>.md
```

Не сохраняй сюда только ссылку без стенограммы: доступ к исходному чату позднее может отсутствовать. Не помещай в архив секреты и материалы, которые запрещено сохранять или публиковать в репозитории vault.
